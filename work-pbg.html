아트, 라이프 몰 리뉴얼 | 2026.04 – 2026.08
+107%방문자 (리뉴얼 전후)
+81%회원가입 (리뉴얼 전후)
문제

아트와 라이프 상품이 구분 없이 노출되어 탐색 동선이 부족하고, 가입 및 구매까지의 단계가 많음.

한 일
  • 아트, 라이프 카테고리별 메인 페이지 신규 설계
  • 주간 랭킹, 신상, 트렌딩 섹션 및 랭킹 페이지 추가로 탐색 동선 확장. 아트는 작가, 작품명, 가격 / 라이프는 브랜드, 할인율, 별점으로 카드 정보 차별화
  • 카카오, 네이버, 아이디 로그인을 한 화면에 제공하는 통합 로그인으로 가입 장벽 완화
  • 구매하기와 장바구니를 분리해 주문서로 바로 이동하도록 개선
  • 신규 메인 슬롯별 GA4 이벤트 설정으로 리뉴얼 성과 측정 체계 구축
결과

리뉴얼 전후 비교 방문자 107%, 회원가입 81% 증가.

통합 데이터 대시보드 구축

통합 데이터 대시보드 | 2026.07 – 진행 중 | 기여도 100%
+45%도입 후 월평균 거래액
121개메인 진열 슬롯 성과 추적
매일Slack 매출 리포트 자동 발송
2종지표 오염원 분리 (광고·봇)
문제 상황

매출(Cafe24)과 행동 데이터(GA4)가 분리되어 한 화면에서 성과 판단 불가. 메인 진열 슬롯별 성과 파악이 어렵고, 일일 매출은 수기로 집계.

문제 정의

지표 자체의 신뢰도가 낮음.

  • 제휴 광고 유입과 해외 봇 트래픽(평균 체류 약 2초)이 섞여 전환율 및 퍼널 왜곡
  • 구매하기, 장바구니 버튼 구조 변경으로 기존 퍼널 정의와 불일치
해결 과정
  • Cafe24 API와 GA4를 연동한 AARRR 통합 대시보드 구축
  • 아트 61개, 라이프 60개 진열 슬롯 매핑으로 슬롯 단위 클릭 및 매출 추적
  • 광고 유입 분리, 봇 트래픽 플래그 처리 및 변경된 버튼 구조에 맞춘 퍼널 재정의
  • GMV, 매출총액, TOP 5, 목표 달성률 리포트 내부 서버에서 매일 자동 발송
  • 개발팀 리소스 투입 없이 AI를 활용해 API 연동 구현 및 내부 서버 연동
결과
  • 대시보드 도입(2026.07) 이후 3개월 월평균 거래액(GMV) 45% 증가 (도입 전 4개월 대비)
  • 필요한 지표를 정의하고 매출을 수치화해 목표 대비 예측 가능
  • 의사결정권자와 운영, MD 담당자가 동일한 데이터로 매일 성과 확인
  • 통합 데이터를 통해 손익 구조 문제 및 알림 과다로 인한 회원 탈퇴 급증 발견
  • 탐색 확장(랭킹, 신상, 트렌딩)을 우선 과제로 선정하는 근거로 활용
배운 것

대시보드 구축보다 지표 정의가 우선되어야 하며, 데이터 오염 요인을 먼저 제거해야 의사결정에 활용할 수 있다는 점을 배웠습니다.

아트 커머스 주문 데이터 처리

운영 데이터 | 2025.12 – 재직 중
문제

작품마다 사이즈, 액자, 에디션 옵션이 다르고 매입, 위탁 상품이 혼재하며 수장고에서 직접 출고. 일반 커머스보다 주문 데이터가 복잡해 정산 및 분석이 어려움.

한 일
  • Cafe24 상품과 ERP(이카운트) 품목을 맞추는 맵핑 작업을 설계하고 진행
  • 흩어진 주문 알림 데이터를 분석 가능한 시트로 구조화
  • 수장고 출발 기준 거리 및 권역별 운송료를 바탕으로 고객 배송비 정책 설계
  • 자사몰 및 외부 입점 매출 비중, 매입 및 위탁 매출 등 월별 경영 자료 추출
