# 김수 Product Portfolio

GitHub Pages로 배포하는 정적 포트폴리오 사이트.

- `index.html` 메인 페이지 (케이스 스터디 4개 + Other Work + About)
- `img/` 슬라이드·썸네일·프로필 이미지
- `pdf/` 이력서·포트폴리오 PDF (사이트에서 링크)

## 배포
1. 새 public 저장소를 만든다 (예: `portfolio`, 또는 `<아이디>.github.io`).
2. 이 폴더의 파일을 그대로 올린다.
3. Settings → Pages → Branch: `main` / root 로 저장.
4. `https://<아이디>.github.io/portfolio/` 에서 확인.
